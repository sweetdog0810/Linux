# L01 与《Linux基础与应用开发实战指南》的对应关系

## 核心必读

1. 第 28 章《文件操作与系统调用》
   - 28.4 Linux 系统调用
   - 28.6 文件操作（系统调用）
   - 重点：`open/read/write/close` 与文件描述符

2. 第 32 章《串口通讯与终端设备》
   - 32.1 串口通讯简介
   - 32.2 终端设备
   - 32.2.1 终端设备文件
   - 32.2.2 `stty` 命令
   - 32.3.5 与 Ubuntu 主机通讯
   - 32.4 串口通讯实验（系统调用）
   - 32.4.1 实验代码分析
   - 32.4.2 `termios` 结构体
   - 32.4.3 编译及测试
   - 32.5 `ioctl`：理解即可，L01 不要求自己直接用 ioctl 配置串口

3. 第 36 章《信号》
   - 36.1 信号基本概念
   - 36.2 信号处理
   - 36.3.2 `sigaction()`
   - 重点：Ctrl+C -> SIGINT -> 设置退出标志 -> 正常清理

4. 第 41 章《线程》
   - 41.1 线程和进程
   - 41.2 创建线程
   - 41.4 线程退出
   - 41.5 线程实验
   - 本项目 C++ 使用 `std::thread`，概念对应 Linux/POSIX pthread

5. 第 43 章《POSIX互斥锁》
   - 43.1 基本概念
   - 43.2 初始化
   - 43.3 获取与释放
   - 43.4 销毁
   - 43.5 实验
   - 本项目 C++ 使用 `std::mutex`，用于日志、控制台输出和串口写入保护

6. 第 46 章《深入了解 select、poll、epoll 之间的区别》
   - 46.4 阻塞 I/O
   - 46.5 非阻塞 I/O
   - 46.6 多路复用 I/O
   - 46.6.2 `poll`
   - L01 只要求掌握 `poll`，暂不深入 `epoll`

## L00 需要回顾

- 第 7 章：`/dev` 等 Linux 文件目录
- 第 8 章：用户组和文件权限
- 第 9 章：命令行
- 第 21 章：Git
- 第 23、26、27 章：GCC / Makefile

## 本项目额外工程化内容

教材不会完整覆盖本项目的以下组合设计：

- C++17 RAII 封装 `SerialPort`
- `std::thread` / `std::mutex`
- PTY 伪串口自动集成测试
- VS Code Tasks
- L00 回归测试 + L01 串口测试

这些属于项目工程化补充。
